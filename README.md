### studio-user-stories
# User centric design solutions for Studio 2

Victor wants a website designed to help with tracking progress of students in Maths ID101
```
User - a type of user (student, lecturer)  
What needs to be done - I want to be able to do A, B and C  
Target outcome
```

***Lecturer***  
***To be done*** - Wants to be able to easily view individual student progress, ranked from top current overall marks to bottom  
***Outcome*** - Easily able to identify students that may need additional help to improve

***Student***  
***To be done*** - Wants to be able to view their progress and related marks  
***Outcome*** - Ability to identify areas they may need to practice (and areas they are confident in)

***Student***  
***To be done*** - Wants easy access to the different course modules (statistics, logic, cryptography)  
***Outcome*** - Feature to navigate the course material in a clean and obvious way
